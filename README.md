# Calculadora de Contenções — Downloads

Software para análise e dimensionamento de contenções: muro de gravidade
(pedra argamassada, concreto ciclópico, gabião), muro de flexão, cortina
atirantada, estaca-prancha, parede de estacas e solo grampeado.

Verificações conforme ABNT NBR 11682, 6122, 5629, 16920-2, 6118:2023 e 6120:2019.

## ⬇ Baixar

Acesse **[Releases](../../releases/latest)**, baixe o arquivo `.zip`,
descompacte e execute `CalculadoraContencoes.exe`.

- Windows 10 ou 11 (64 bits) — não requer instalação.
- Se o Windows SmartScreen exibir "aplicativo não reconhecido", clique em
  **Mais informações → Executar assim mesmo**.
- O programa avisa automaticamente quando houver uma versão mais nova.
